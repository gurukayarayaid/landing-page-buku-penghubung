2.2 Berkas project

Siapkan folder project buku-penghubung (hasil unduh ZIP/RAR) di lokasi mudah, contoh: D:\buku-penghubung. Isinya kira-kira seperti ini:

Struktur folder project
buku-penghubung\
├── app\              => kode aplikasi (web) yang di-deploy
│   ├── index.html
│   ├── js\config.js   => BERKAS INI YANG KITA ISI
│   └── css\, icons\, models\
├── android\          => proyek Android untuk build APK
├── cloudflare\        => worker.js + wrangler.toml
├── firebase\          => aturan keamanan database & storage
├── firebase.json      => konfigurasi deploy (public: "app")
├── .firebaserc        => nama project Firebase
├── PASANG-FIREBASE.bat => KLIK 2x untuk isi config otomatis
└── build-release.bat  => build APK sekali jalan
⚠️ Penting: semua perintah di panduan ini dijalankan dari folder induk buku-penghubung, bukan dari dalam folder app. firebase.json harus berada sejajar dengan folder app.

📌 Catat nama project (contoh: buku-penghubung-abc12) — nama ini dipakai pada alamat situs https://NAMA.web.app.

3.2  Aktifkan Realtime Database & Storage

1

Build → Realtime Database → Create Database

Di menu kiri pilih Build → Realtime Database → klik Create Database.

⚠️ Jangan lewati langkah ini. Kalau Realtime Database belum dibuat, aplikasi akan menampilkan error "database not found" walaupun konfigurasi sudah benar. Ulangi juga untuk Storage (Build → Storage → Get started) sebagai cadangan.
2

Periksa alamat database

Di halaman Realtime Database, salin alamat yang tertera di atas tabel data, bentuknya:

https://<nama-project>-default-rtdb.asia-southeast1.firebasedatabase.app

Pastikan tulisannya asia-southeast1 (singapura) — kalau salah wilayah, data tidak akan tersambung.

3.3  Salin konfigurasi & isi config.js

1

Ambil blok firebaseConfig

Klik ikon ⚙ Settings (roda gigi, pojok kiri atas) → tab General → gulir ke bagian Your apps → klik ikon web </> → beri nama (mis. buku-penghubung) → Register app.

Muncul blok kode firebaseConfig berisi apiKey, authDomain, databaseURL, projectId, dll. Salin semuanya.

console.firebase.google.com/project/<nama-project>/settings/general

Your apps — SDK setup
📋 Blok firebaseConfig di atas yang harus Anda salin seluruhnya.
2

Tempel ke berkas fb.txt

Di folder project, buka (atau buat) berkas teks bernama fb.txt memakai Notepad, lalu tempel hasil salinan tadi. Simpan dengan Ctrl+S.

3

Jalankan PASANG-FIREBASE.bat

Klik dua kali berkas PASANG-FIREBASE.bat di folder project. Skrip akan membaca fb.txt lalu:

  • mengisi app\js\config.js secara otomatis (tanpa salah ketik),
  • menyalin seluruh folder app\ ke android\app\src\main\assets\www\,
  • menampilkan nilai yang terpasang untuk Anda periksa.
keluaran yang diharapkan
MEMASANG KONFIGURASI FIREBASE
  Membaca fb.txt ...
  [OK] app/js/config.js diperbarui
  [OK] app/* disalin ke android/.../assets/www/
  apiKey     : AIzaSy........................
  databaseURL: https://.....asia-southeast1...
  SELESAI. Tutup jendela ini.
4

Periksa databaseURL

Nilai ini sering tidak ikut di blok konfigurasi. Buka app\js\config.js, pastikan barisnya lengkap dan wilayahnya benar:

databaseURL: "https://<nama-project>-default-rtdb.asia-southeast1.firebasedatabase.app",

Kalau berbeda, betulkan manual lalu salin ulang folder app ke assets/www.

🔎 Tanda berhasil: buka aplikasi — tulisan "MODE DEMO" di bagian atas harus hilang. Kalau masih muncul, berarti apiKey atau databaseURL masih kosong: ulangi langkah 3.3.

3.4  Pasang aturan keamanan

Database masih dalam test mode (terbuka untuk semua orang) dan akan kedaluwarsa dalam 30 hari. Setelah lewat, semua akses ditolak dan aplikasi berhenti bekerja. Aturan sudah disiapkan di folder firebase\.

PowerShell — di folder induk project
firebase login                    # sekali saja, ikuti petunjuk di browser
firebase deploy --only database,storage

Cara manual (tanpa terminal): buka Realtime Database → tab Rules → tempel isi firebase\database.rules.json → klik Publish. Ulangi untuk Storage dengan firebase\storage.rules.

⚠️ Aturan bawaan memuat node pengaturan yang dipakai fitur Hari Efektif & Libur. Pakai berkas yang disediakan, jangan aturan lama.

3.5  Deploy (terbitkan) ke Firebase Hosting

PowerShell — dari folder induk project
firebase deploy --only hosting

found 14 files in app
hosting[buku-penghubung-f579b]: file upload finished
hosting[buku-penghubung-f579b]: https://<nama-project>.web.app  COMPLETE ✓

✅ Harus muncul

found 14 files in app
Artinya hanya isi folder app yang diunggah.

❌ Salah umum

found 78 files in .
firebase.json masih memakai "public": ".".

✄️ Saat init

Kalau ditanya "index.html already exists. Overwrite?" jawab No — kalau terlanjur Yes, tampilan aplikasi hilang.

💡 Isi firebase.json yang benar (sudah tersedia di project, pastikan public menunjuk folder app):
firebase.json
{
  "database": { "rules": "firebase/database.rules.json" },
  "storage":  { "rules": "firebase/storage.rules" },
  "hosting":  { "public": "app", "ignore": ["**/.*", "**/node_modules/**"] }
}

Cloudflare R2 — Penyimpanan Media

Tempat file foto, video, audio, dan PDF. Opsional, tapi sangat disarankan.

Mengapa perlu Cloudflare?

  • Gratis: 10 GB penyimpanan
  • Unduhan (egress) tanpa batas & gratis
  • 1 juta operasi tulis + 10 juta baca per bulan
  • Worker 100 ribu request per hari

Alur singkat

HP (upload) → Worker (validasi)
→ R2 (simpan file)
→ URL file dibagikan ke chat

1

Buat akun Cloudflare

Buka https://dash.cloudflare.com/sign-up → daftar dengan email → verifikasi email.

2

Buat R2 Bucket

Login → di menu kiri pilih R2 → Create bucket.

  • Bucket name: bpd-media (harus sama dengan isi wrangler.toml)
  • Location: terdekat — misal APAC / Singapore
  • Storage class: Standard
3

Aktifkan Public Access

Pada bucket → tab Settings → bagian Public access → Allow Access → centang Allow public access.

📌 Catat URL publik yang muncul, contoh: https://pub-xxxxx.r2.dev — dipakai di langkah 6.
4

Buat API Token

Di halaman R2 klik Manage R2 API Tokens → Create API token:

  • Token name: bpd-upload
  • Permissions: Object Read & Write
  • Specify bucket: pilih bucket bpd-media

Klik Create API Token lalu catat Access Key ID, Secret Access Key, dan Endpoint — hanya muncul sekali.

5

Install & login Wrangler

Wrangler adalah alat resmi Cloudflare untuk mengirim Worker ke internet.

PowerShell
npm install -g wrangler     # atau tanpa install: npx wrangler
npx wrangler login          # browser terbuka → klik Allow
node -v                     # minimal v18
6

Isi secret PUBLIC_DOMAIN

Worker butuh tahu alamat publik bucket untuk membuat URL file.

PowerShell — masuk ke folder cloudflare dulu
cd cloudflare
npx wrangler secret put PUBLIC_DOMAIN

? Enter value: https://pub-xxxxx.r2.dev   <- paste URL hasil langkah 3
7

Deploy Worker

PowerShell
npx wrangler deploy

Uploaded bpd-upload-media
Deployed bpd-upload-media triggers
  https://bpd-upload-media.<username>.workers.dev  ✓
📌 Catat URL Worker (bentuk ….workers.dev) — URL ini yang dimasukkan ke aplikasi pada langkah berikutnya.
8

Sambungkan ke aplikasi (app/js/config.js)

Buka berkas app\js\config.js, cari bagian R2_CONFIG, lalu ganti isinya:

app/js/config.js
var R2_CONFIG = {
  workerUrl : "https://bpd-upload-media.<username>.workers.dev",
  publicUrl : "https://pub-xxxxx.r2.dev",
  enabled   : true
};
9

Deploy ulang & uji upload

Perubahan config belum aktif sampai diunggah ulang:

firebase deploy --only hosting

Uji: login sebagai guru → buka chat salah satu murid → klik 📎 → pilih Gambar → tunggu sampai tampil di chat. Selesai! ✅

5

Build APK Android

Menghasilkan berkas .apk yang di-install di HP wali murid.

5.1 Persiapan

  • Install Android Studio (developer.android.com/studio)
  • Install JDK 17 (ikut terpasang bersama Android Studio)
  • Buka Android Studio sekali sampai selesai & setuju dengan lisensi

5.2 Jalankan build

Cara termudah: klik dua kali berkas build-release.bat di folder project. Skrip mencari Android SDK otomatis lalu menjalankan build.

Cara manual lewat terminal:

PowerShell
cd android
.\gradlew.bat assembleRelease

BUILD SUCCESSFUL in 2m 14s

5.3 Di mana hasilnya?

lokasi berkas APK
android\app\build\outputs\apk\release\
   └── app-release.apk   (salin & ganti nama, mis. ...-v1.6-release.apk)

📌 Supaya APK bisa dipasang

Build release harus ditandatangani (signed). Buat berkas android\keystore.properties lalu build ulang. File keystore (mis. wabcraft-release.jks) harus dijaga & dibackup.

🛠️ Versi aplikasi

Ubah nomor versi di android\app\build.gradle: versionName "1.6" dan versionCode 7.

⚠️ APK versi release memakai isi folder android\app\src\main\assets\www\, bukan folder app\. Itu sebabnya PASANG-FIREBASE.bat menyalin otomatis. Jika Anda mengedit config.js setelah build, build ulang APK-nya.
6

Daftar Periksa Akhir

Centang satu per satu sebelum membagikan aplikasi ke wali murid.

Firebase

  • Realtime Database sudah dibuat, lokasi asia-southeast1, mode test aktif
  • Blok firebaseConfig sudah ditempel ke fb.txt & PASANG-FIREBASE.bat dijalankan
  • databaseURL di config.js lengkap & benar wilayahnya
  • Tulisan MODE DEMO sudah tidak muncul di aplikasi
  • Aturan database & storage sudah di-deploy (firebase deploy --only database,storage)
  • Hosting terbit & muncul found 14 files in app
  • Uji dua HP berhasil (pesan masuk real-time)

Cloudflare (kalau dipakai)

  • Bucket bpd-media dibuat & Public access aktif
  • Secret PUBLIC_DOMAIN terisi dengan URL publik R2
  • Worker ter-deploy, URL .workers.dev tercatat
  • R2_CONFIG terisi & enabled: true
  • Upload foto dari HP berhasil tampil di chat

APK & Distribusi

  • APK berhasil di-build (BUILD SUCCESSFUL) & sudah di-sign
  • APK terpasang & bisa login di HP Android uji coba
  • Nama sekolah, kelas, tahun ajaran di config.js sudah disesuaikan
  • Daftar murid (NIS & nama) sesuai kelas yang akan dipakai
  • Alamat web dibagikan ke wali murid + panduan singkat pemakaian
🇁‍💼 Keamanan singkat: ganti kata sandi admin bawaan di APP.adminPassword (config.js) sebelum dibagikan, dan jangan sebarkan berkas keystore APK.
7

Masalah Umum & Cara Mengatasinya

Cari gejalanya di kolom kiri, lalu kerjakan solusinya.

GejalaPenyebab & Solusi
Masih tertulis "MODE DEMO" apiKey / databaseURL masih kosong. Jalankan ulang PASANG-FIREBASE.bat. Kalau lewat APK, pastikan config.js juga tersalin ke assets\www\js\.
"database not found" Realtime Database belum dibuat di Console. Kerjakan langkah 3.2, lalu deploy ulang.
"Permission denied" di console browser Aturan belum di-publish, atau test mode sudah lewat 30 hari. Jalankan firebase deploy --only database,storage.
Pesan tidak muncul di HP lain Kedua perangkat harus memakai FIREBASE_CONFIG yang sama persis. Periksa juga databaseURL — salah wilayah berarti data masuk ke database lain.
Deploy gagal: "Executable files are forbidden on the Spark billing plan" firebase.json memakai "public": "." sehingga file Android ikut terunggah. Ubah menjadi "public": "app".
Halaman "Firebase Hosting Setup Complete" index.html tertimpa. Salin ulang dari android\app\src\main\assets\www\index.html, lalu deploy lagi.
Upload foto gagal / "Gagal koneksi ke R2" Periksa R2_CONFIG.workerUrl benar & enabled: true; secret PUBLIC_DOMAIN sudah diisi; bucket sudah Public access.
"Tipe file tidak diizinkan" Yang diizinkan: jpg, png, gif, webp, mp4, webm, mp3, m4a, PDF — maksimal 20 MB.
Tombol Pengaturan Hari Efektif gagal menyimpan Aturan database belum punya node pengaturan. Pakai firebase\database.rules.json bawaan.
Build APK gagal / "ANDROID_HOME belum diset" Install Android Studio, buka sekali, lalu jalankan lagi build-release.bat (skrip mencari SDK otomatis).
Wrangler: "not logged in" / deploy gagal Jalankan npx wrangler login, pastikan Node.js ≥ 18, dan nama bucket di wrangler.toml sama dengan di Cloudflare.
🚨 Jika semua gagal: periksa dulu koneksi internet dan ulangi perintah dari folder induk project. Sebagian besar kesalahan pemula berasal dari folder yang salah saat mengetik perintah.

8.2 Pertanyaan umum

Q: Harus bisa coding?
Tidak. Ikuti langkahnya saja; bagian yang perlu diubah sudah disiapkan berkasnya.

Q: Bisa dipakai untuk sekolah lain / kelas lain?
Bisa. Buat project Firebase baru, ubah nama sekolah, kelas, dan daftar murid di app/js/config.js, lalu deploy.

Q: Bagaimana di akhir tahun ajaran?
Kosongkan data lama lewat menu guru Reset Data, hapus isi bucket R2, lalu perbarui daftar murid & tahun ajaran.
